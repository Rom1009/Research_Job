REQUIREMENTS
Job Purpose
The Front-End Developer will be responsible for designing and implementing user interfaces for web and mobile applications, ensuring usability, responsiveness, and visual consistency. This role combines front-end development expertise with basic UI/UX design skills to deliver intuitive and engaging user experiences in the absence of a dedicated UX/UI designer.
Key Responsibilities
Design and implement user interfaces for web and mobile platforms using modern frameworks (ReactJS, React Native).
Develop and maintain user-facing features ensuring responsive design and accessibility standards.
Create wireframes and mockups to visualize layouts and user flows.
Collaborate with product owners and stakeholders to translate requirements into functional and visually appealing interfaces.
Integrate APIs and work closely with back-end developers for seamless data exchange.
Optimize application performance and ensure cross-browser compatibility.
Maintain code quality through testing, debugging, and adherence to best
practices.
Stay updated on emerging front-end technologies and design trends.

Soft Skills:
